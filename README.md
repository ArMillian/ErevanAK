# Երևան · Քաղաքի հիշողությունը

Ապաարխիվացրեք ամբողջ փաթեթը և բացեք `index.html` ֆայլը ժամանակակից դիտարկիչով։ Համացանց կամ տեղական սերվեր հարկավոր չէ։ Բոլոր լուսանկարներն ու գծանկարները գտնվում են `assets` պանակում։

## Управление

- **← и →** переключают слайды. Также работают колесо, нижние индикаторы, экранные стрелки и горизонтальный свайп.
- **F** включает и выключает полный экран. **Esc** возвращает в оконный режим.
- На пятом слайде перетаскивайте разделитель. С клавиатуры перейдите к нему клавишей **Tab** и используйте стрелки. Следующее нажатие **Tab** возвращает стрелкам управление слайдами.
- При включённой в системе настройке уменьшения движения переходы становятся мгновенными.
- Авторы фотографий, лицензии и исторические источники перечислены в `SOURCES.md`.

**Запуск в Windows.** Распакуйте ZIP целиком и дважды нажмите `index.html`. Рекомендуемое разрешение для выступления — 1920 × 1080.


## Публикация на GitHub Pages

1. Распакуйте архив. Загрузите его содержимое в корень ветки `main` вашего репозитория. Файл `index.html`, папка `assets`, стили и сценарий должны лежать рядом, как в архиве.
2. В репозитории откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**. Нажмите **Save**.
3. После завершения публикации нажмите **Visit site** в этом разделе. По той же ссылке презентация откроется на компьютере, планшете и телефоне.

Проект использует относительные пути и обходится без сборки и CDN. Локальный запуск по-прежнему работает двойным щелчком по `index.html`. Кнопка «Աղբյուրներ» показывает литературу и авторов изображений текущего слайда. Список доступен офлайн, для перехода на сайты источников нужен интернет.
